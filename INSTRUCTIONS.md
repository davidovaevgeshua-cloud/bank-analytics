# Как установить в репозиторий bank-analytics

## 1. Новые файлы — просто добавить

Скопируйте в репозиторий (сохранив структуру папок):

```
scripts/cbr_forms_parser.py       — парсер dbf для форм 101/123/135
scripts/classify.py               — классификация счетов формы 101 по категориям
scripts/download_capital_forms.py — загрузка архивов форм 101/123/135
scripts/compute_capital.py        — расчёт капитала/нормативов/структуры баланса за период
scripts/render_capital.py         — сборка данных для вкладки "Капитал" (ROE/ROA, Н1.0, структура)
scripts/update_capital_data.py    — оркестратор обновления (аналог update_data.py для CIR)
scripts/render_combined.py        — сборка единого index.html из CIR + капитала
data/capital_history.json         — история капитала/баланса, дек. 2023 – июн. 2026 (посчитана заранее)
data/capital_state.json           — последний обработанный период ("062026")
```

## 2. Файлы для замены (изменились)

```
scripts/report_template.html   — теперь с двумя вкладками: "CIR" и "Капитал, ROE / ROA, структура баланса"
scripts/update_data.py         — одна правка: в конце вызывается render_combined.render()
                                  вместо render_report.render(), чтобы обновление CIR не затирало
                                  вкладку "Капитал"
.github/workflows/update.yml   — добавлен шаг "python scripts/update_capital_data.py" после
                                  существующего шага CIR
```

## 3. Без изменений — ничего делать не нужно

`scripts/compute_cir.py`, `scripts/dbf_parser.py`, `scripts/download_period.py`,
`scripts/render_report.py`, `data/cir_history.json`, `data/state.json` — остаются как есть.
`render_combined.py` только импортирует функции из `render_report.py`, не меняя его.

## 4. Единый список банков

В `render_capital.py` список банков (13 шт.) взят из `compute_cir.py` (`BANKS`, `BANK_ORDER`) —
теперь обе вкладки показывают один и тот же набор: Сбербанк, ВТБ, Альфа-Банк, Газпромбанк,
ТБанк, ВБ Банк, Совкомбанк, Банк ДОМ.РФ, Райффайзенбанк, Россельхозбанк, МКБ, Яндекс Банк,
Озон Банк.

## 5. Важно проверить перед первым автозапуском

URL-шаблон для скачивания архивов форм 101/123/135
(`https://www.cbr.ru/vfs/credit/forms/{форма}-{ГГГГММ01}.rar`) выведен по аналогии с уже
подтверждённым шаблоном формы 102 и с именами архивов, с которыми велась работа при
первичном сборе данных (например, `123-20241101.rar`). Из песочницы, где готовился этот
пакет, cbr.ru заблокирован для исходящих запросов — поэтому шаблон **не проверен вживую**.

Как проверить: откройте в браузере
`https://www.cbr.ru/vfs/credit/forms/123-20260701.rar` — если файл скачивается, шаблон верный
и ничего менять не нужно. Если 404/ошибка — сверьте точный адрес на
https://www.cbr.ru/banking_sector/otchetnost-kreditnykh-organizaciy/ и поправьте
`BASE_URL_TEMPLATE` в `scripts/download_capital_forms.py`.

Также первый прогон workflow (кнопка "Run workflow" в GitHub Actions, вкладка Actions) стоит
запустить вручную и проверить лог — если данные за 07/2026 и позже подтянутся без ошибок,
всё настроено верно и дальше workflow будет обновлять обе вкладки каждый день в 09:00 по
Москве автоматически, как и раньше с CIR.

## 6. Тестирование, которое уже сделано в этой сессии

- `render_combined.py` прогнан на реальных данных (`data/cir_history.json` с GitHub +
  свежепосчитанный `data/capital_history.json`) — index.html собирается без ошибок.
- Итоговый HTML проверен через headless-тест (jsdom): 0 ошибок JS, обе верхние вкладки
  переключаются корректно, вложенные вкладки "сектор/по банку" работают, выпадающие списки
  банков (по 13 пунктов в каждой вкладке) и таблицы рендерятся, смена банка в CIR-вкладке
  корректно обновляет график и текстовый вывод.
- Сама логика расчёта капитала/нормативов/ROE/ROA — это тот же код, что уже проверен на
  реальных данных ЦБ РФ (сверка с Сбербанком/ВТБ, независимая оценка Н1.0 по сектору ~13,9%
  против расчётных ~14,1%) в ходе построения отдельного дашборда ранее в этой сессии.
- НЕ протестировано вживую: сама загрузка архивов 101/123/135 с cbr.ru (см. пункт 5) —
  единственное, что нельзя было проверить из песочницы.
