# bank-analytics — автообновление CIR банковского сектора (форма 102 ЦБ)

## Что тут лежит

- `index.html` — сама страница отчёта (то, что откроется по ссылке GitHub Pages).
- `data/cir_history.json` — накопленная история по всем периодам (сырые компоненты
  ЧПД / чистых комиссий / АХР в млрд руб. по 13 банкам и по сектору), уже
  заполнена данными за январь 2025 – май 2026.
- `data/state.json` — последний успешно обработанный период; отсюда скрипт
  понимает, с какого месяца продолжать при следующем запуске.
- `scripts/dbf_parser.py` — чтение dbf-файлов формы 102 (свой парсер, потому что
  библиотека `dbfread` не справляется с полем REGN в справочнике банков).
- `scripts/download_period.py` — скачивание и распаковка архива ЦБ за один период.
- `scripts/compute_cir.py` — расчёт CIR и работа с накопительной историей.
- `scripts/render_report.py` — сборка `index.html` из истории.
- `scripts/update_data.py` — главный скрипт: проверяет, вышли ли новые данные у
  ЦБ, и если да — прогоняет всю цепочку и пересобирает страницу.
- `.github/workflows/update.yml` — расписание: GitHub Actions запускает
  `update_data.py` каждый день в 06:00 UTC (09:00 мск) и сам коммитит изменения,
  если они появились.

## Как включить сайт (один раз)

1. Загрузите все файлы из этой папки в свой репозиторий на GitHub, сохранив
   структуру папок (`.github/workflows/update.yml`, `scripts/...`, `data/...`,
   `index.html`).
2. В репозитории: **Settings → Pages → Build and deployment → Source** —
   выбрать **Deploy from a branch**, ветка **main**, папка **/ (root)**, Save.
3. Через минуту-две GitHub покажет ссылку на сайт (обычно
   `https://<ваш-логин>.github.io/<имя-репозитория>/`).

## Как проверить, что автообновление работает

Не обязательно ждать следующего отчётного периода ЦБ — можно запустить
workflow вручную: вкладка **Actions** → слева workflow **"Обновление данных
CIR"** → кнопка **Run workflow**. В логе будет видно, что скрипт сделал:
нашёл новый период и обновил данные, либо сообщил, что ЦБ его ещё не
опубликовал (это нормальная ситуация, не ошибка).

## Важное ограничение, о котором стоит знать

Шаг скачивания архива с сайта ЦБ (`download_period.py`) я не могла
протестировать вживую в своей среде — она обращается только к ограниченному
списку сайтов, и cbr.ru в него не входит. Сам адрес и формат ссылок я
подтвердила напрямую по официальной странице ЦБ
(https://www.cbr.ru/banking_sector/otchetnost-kreditnykh-organizaciy/), но
первый реальный запуск стоит проверить по логу Actions — вдруг понадобится
небольшая правка (например, в том, как называется файл `_P1.dbf` внутри
конкретного архива).
